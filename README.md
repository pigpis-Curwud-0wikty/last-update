# 🛍️ R & S E-Commerce

> A modern and fully responsive e-commerce web application built with React.js and Tailwind CSS.

🔗 **Live Demo:** https://r-and-s-one.vercel.app/  
🔗 **Backend API Documentation:** https://fashion-v1.runasp.net/swagger/index.html  

---

## 📌 About The Project

**R & S E-Commerce** is a modern online shopping platform that delivers a fast, clean, and intuitive user experience.  

The frontend is built using **React.js** and **Tailwind CSS**, while the application integrates with a live custom backend API developed using **ASP.NET**.

The project demonstrates strong frontend architecture skills, API integration, reusable components design, and responsive UI implementation.

The backend API was developed by **Omar Gamal**.  
🔗 Portfolio: https://portfolionet-one.vercel.app/

---

## 🚀 Features

✔ Product browsing with dynamic data from API

✔ Product details page
